This page can’t be read aloud

Firefox does not allow add-ons to run on this page.

Why PDFs in particular

Firefox opens PDFs in a viewer of its own, and it does not let any add-on see inside that viewer. This add-on never gets to look at the page, so it cannot find the text, and no setting or permission changes that.

This is not specific to this add-on. It applies to every Firefox add-on, and it has been this way since Firefox 60. Mozilla is aware of it — the request to allow it again has been open for years and was reopened recently, but it has not been done.

What you can do instead

Firefox’s own PDF viewer works with screen readers, and you can select text in it and copy it elsewhere. Saving the PDF and opening it again will not help: the restriction is the same either way.

If a paper also exists as a normal web page — many journals publish an HTML version alongside the PDF — this add-on will read that version normally.

Follow the Firefox request to allow this

Why Firefox’s own pages

Pages that belong to Firefox itself — settings, about: pages, and the add-on’s own screens — are off limits to add-ons. This is a security rule built into the browser, and it protects you: an add-on that could rewrite your settings page could hide what it was doing.

Why this site

Mozilla blocks add-ons on its own websites, including the add-ons site itself. It is the same protection as for Firefox’s settings: it stops an add-on from interfering with the place you go to remove it.

This one is unexpected

This page is not a PDF and not one of Firefox’s own pages, so the add-on should have been able to read it. Something stopped it from starting.
